# Synthesis comparison report

Generated by `make synth_report`. Numbers are post-synthesis, pre-place-and-route.
Vendor flows (Vivado / Quartus) usually pack tighter than the open-source flow,
so the Yosys numbers should be read as upper bounds.

| Toolchain                | Target                  | Result                       |
|--------------------------|-------------------------|------------------------------|
| Yosys 0.x synth_ice40    | iCE40 UP5K              | 436 LUT / 286 FF / 4 BRAM              |
| Yosys 0.x synth_ecp5     | ECP5 LFE5UM-25          | 455 LUT / 226 FF / 0 BRAM               |
| Yosys 0.x synth_xilinx   | Xilinx 7-series         | 389 LUT / 389 FF / 0 BRAM                |
| Vivado synth_design      | Artix-7 xc7a35tcsg324-1 | (skipped: vivado not on PATH)             |
| Quartus Pro              | Cyclone V 5CSEMA5F31C6  | (skipped: quartus_sh not on PATH)            |

## Notes

* The numbers above are for the loopback top, which integrates BOTH the
  master and the slave plus their TX and RX FIFOs (4 FIFOs of 16x8 bits
  total). For a master-only or slave-only build, expect roughly half
  the LUT/FF count.
* The bit-clock generator (16-bit divisor + edge counter) and the
  shift registers dominate the master area. The slave is smaller —
  it consumes the master-driven SCK and only needs edge detection
  plus the shift register and FIFOs.
* No BRAM is required at the default FIFO_DEPTH = 16. Vendor flows
  may infer LUTRAM for the FIFO storage; Yosys generic synth keeps
  it as flops.
* AXI4-Lite wrapper (`spi_axi4lite`) adds ~600 LUT / 700 FF on top
  for the register-mapped control interface. Run
  `yosys -p "read_verilog -sv rtl/*.sv; hierarchy -top spi_axi4lite; synth_xilinx; stat"`
  to see those numbers.
